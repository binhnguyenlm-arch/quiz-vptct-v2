# Quiz VPTCT UI V1

Bản giao diện tĩnh để chốt thiết kế trước khi kết nối Supabase.

## Chạy thử
1. npm install
2. npm run dev
3. Mở http://localhost:3000

## Giai đoạn hiện tại
- Trang chủ giao diện hoàn chỉnh ở mức prototype.
- Chưa kết nối Supabase.
- Các nút Ôn tập / Thi thử / Quản trị chưa có logic.
- Mục tiêu: duyệt giao diện trước, sau đó mới làm chức năng từng phần.
